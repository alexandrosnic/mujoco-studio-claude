# Changelog

## 0.1.0 — 2026-11-23

First version.

- `mujoco-studio` skill: workflow for building a MuJoCo scene from a prompt,
  testing it headless and showing it in the MuJoCo Studio web viewer.
- `studio.sh` helper: `setup`, `new`, `start`, `status`, `context`, `url`,
  `stop`, `python`, `menagerie`, `paths`.
- Starter templates: scene, controller, Studio plugins and a headless test.
- Example: UR5e with a Robotiq 2F-85 gripper picking and placing three cubes.
